# Host executable boundary — 2026-10-13

Windows `execFileSync("git", ...)` selected a project-local `git.exe` even with `NoDefaultCurrentDirectoryInExePath=1`. The harmless probe copied our installed Node executable and ran only `--version`: before/flag-only returned `v24.19.0`; the absolute resolver returned installed Git. No candidate code or credential reads occurred. `windows-probe.json` records the native result.

Resolve Git, gh, Docker and Claude from absolute PATH directories outside both the caller and target directory and all ancestor Git repositories; reject relative/empty PATH and npm `.bin` entries, including symlinks back into these directories. Normalize PATH casing for child processes and pass the resolved executable explicitly. Git `-C` callers also set cwd to the inspected repository. Missing tools retain synchronous/Docker infrastructure-error behavior; Claude resolves before the pending charge entry. Nested Git markers cannot hide an outer repository. Global installation ownership is trusted; this is not executable signature authentication or protection against concurrent replacement of an operator-owned installation.

Local Windows: typecheck/build pass; 543 unit tests passed, one POSIX symlink test skipped. CI must separately confirm Linux PATH resolution, Docker, replay and packaged minimum Node. JSON-escaped unpaired UTF-16 surrogates are also rejected in source/delivery artifacts instead of silently changing bytes on restoration; ordinary emoji/replacement characters remain valid.

Primary implementation references: [Node child process](https://nodejs.org/api/child_process.html), [libuv Windows process](https://github.com/libuv/libuv/blob/v1.x/src/win/process.c). The before/after finding is our measured probe, not an inferred security claim from documentation. No model benchmark or historical score change.

First Opus review found no security blocker but identified global symlink dispatch compatibility. We held the merge until fixing it: validate the real target, execute the absolute global candidate name. Also preserve promise rejection when Claude is absent. The second review covers only these changed parts. POSIX regression test checks dispatch name preservation and rejects project symlink targets. Final Windows count: 543 passed, two platform-specific tests skipped (545 total); CI executes the POSIX checks. Existing bare process.execPath launches are already absolute. The packaged CLI remains bundled and is checked independently in CI on Node 22.19.0.
