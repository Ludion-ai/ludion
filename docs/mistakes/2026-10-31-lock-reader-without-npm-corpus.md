# 2026-10-31 — The lock reader was fixed four times against forms npm writes, with nothing written by npm to check it on

- **What happened.** In #215 (LB2a), four reviews in a row found the same kind of fault in `readLock` and the requirement check (judge.ts): a lockfile form npm writes that the reader got wrong (reviews 6525352604, 6527878093, 6529858505, 6533374683). The latest: the sixth round's closed list of npm 6 tree keys refused `devOptional` and `peer`, which npm 7 to 11 write for ordinary projects, so the PR refused lockfiles main reads. The README said "npm 11.19.1 wrote none of them in the locks here", true only of the four fixtures. Also, where an override applied, a copy meeting the requirement's own range was taken (npm checks only the override's spec), and a moved entry's `peerDependenciesMeta` was not tied to the registry.
- **Why.** Each fix was written from how npm should read a lock and tested on a few locks npm 11.19.1 wrote for that fix. No set of locks from several npm versions and settings, with npm's own verdict on each, existed to check a fix against. So a rule that fit the few fixtures was taken as fitting what npm writes.
- **Fixed in the same PR.** docs/decisions/2026-10-31-lock-corpus-against-npm.md fixed a corpus and its gates before it was made: 50 locks npm 7.10.0 to 11.19.1 wrote at lockfileVersion 2 and 3, 226 one-change variants, and `npm ls --package-lock-only` on each, all in digest-pinned images. The reader now reads every lock in it and refuses nothing main reads. The requirement check agrees with npm on every variant but one form, which Ludion refuses on purpose (another package at a required path; docs/bench/2026-10-31-lb2a-npm-corpus/README.md).
- **Check:** `packages/cli/test/npm-corpus.test.ts` — every lock npm wrote is read, nothing main's reader reads is refused, and the requirement check's disagreements with npm are exactly the 40 V3 variants.
- **Check:** `packages/cli/test/judge.test.ts` — "reads a tree alias by the package it names, and an override key for its own name only (review 6533374683, N4)".
- **Check:** `docs/bench/2026-10-30-lb-design/scripts/mutate.mjs` — a mutation for each change in this round.
- **Rule:** "Every mistake is traced to its cause and fed back into a rule or a check, so the same mistake cannot pass twice."
