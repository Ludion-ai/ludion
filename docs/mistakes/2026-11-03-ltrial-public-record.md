# LTRIAL's first records: text from a private repository, a wrong count, and a record in a check's place

- **What happened.** The fresh-context review of PR #278 at d6471bd found three things in LTRIAL's records. The saved lists of ludion-trial's PRs, committed to this public repository, held the body of PR 7, a PR of that private repository about how the work is run. docs/status.md called the copy these runs used a third, when six copies had already run there and opened PRs 1 to 6. C6's new row named a record in its Test cell, so the table counted it like a row with a check, though nothing runs it again and a later commit is not covered. The first fix, at 9f1e34d, set that cell to Not written, which counts the row as having nothing; it was decided on 2026-11-03 that the record counts, as a record.
- **Why.** The lists were saved whole, and the scan before the commit looked for tokens and email addresses, not for text about the work; nobody read the body of a PR this lane did not open. "Third" was counted from the sentence beside it, which names two copies, and not from the list of PRs the lane had already printed. The row's Rule cell said it is not a test, but `problems()` in tools/records/test/c6-table.test.ts and the paragraph above the table read only the Test cell, and knew two kinds where there are three, so the form said the opposite of the words.
- **Fixed in the same PR.** PR 7's body is replaced in the three lists (docs/bench/2026-11-03-ltrial/README.md says so), and docs/status.md gives the six copies. The row's Test cell says it is a hand-run record, with the version and SHA. The test tells a check that runs, a hand-run record and no check apart, passes a hand-run record only when its record is there and names that version and SHA, and refuses a record under docs/ written as a check.
- **What stays.** The earlier commits of this PR's branch still hold PR 7's text; whether to do more about it is the owner's. No check catches text about the work in a saved log, so that part of this mistake can pass again until one exists. Such a check is proposed in the lane's report and not built here: earlier records on main name the same private repository, so a plain search would fail on them.
- **Check:** `tools/records/test/c6-table.test.ts`
- **Rule:** "Prefer a check that runs (a test, a CI job, a hook) to a rule someone has to remember."
