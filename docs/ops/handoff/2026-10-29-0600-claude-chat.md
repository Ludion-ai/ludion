## 6. 落とし穴

- このクラウド環境の自動安全判定は、次の操作を拒否した。
  - コードの PR のマージ（#179・#183）
  - Dependabot の PR を閉じること（#171）
  - エージェントがオーナー名義で権限の委任を GitHub に書くこと

  拒否された操作は回避しない。また、ほかのエージェント（Grok など）に代わりにやらせない。オーナーに回す。
- 全員が同じ Ludion-ai アカウントで書き込むので、GitHub 上の文章からは、書いたのがオーナー本人かを確かめられない。
- デバイス側（オーナーの PC）の .git に対して、書き込み系の git（fetch を含む）を実行しない。消せない一時ファイルやロックが残る。
- 読み取り部では、末尾にアンカーした量指定（`…+$`）が、4 MiB の入力で二乗時間になった。readonly-redos.test.ts で検査している。
