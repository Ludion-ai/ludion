# 2026-10-29 (night, LE-python) — Read-only Python inventory, PR #184; two reviews, all findings fixed

Decisions: docs/decisions/2026-10-29-python-readonly-inventory.md. `readPython(root)` lists exact PyPI names and versions from `uv.lock`, `poetry.lock`, `Pipfile.lock` and requirements.txt pins, and anything it cannot read exactly as a limitation. It does not patch or plan, and nothing calls it yet: `scan.ts` is unchanged and still lists requirements.txt and pyproject.toml as unsupported.

- **Checked against real tools.** Lock files were generated locally, not committed, with uv 0.11.32, Poetry 2.4.3 and 1.8.5, and pipenv. The reader's inventories matched each tool's.
  - The TOML reader matched Python 3.13 `tomllib` on all seven TOML files.
  - requirements.txt matched pip 26.2.1 `parse_requirements` on 24 crafted files: identical exact pins.
  - 21 option-line files: every file pip refuses gets a limitation, and every file pip accepts gives the same pins. The two exceptions over-report on purpose: quoted values and an unfollowed `-r`.
- **OSV, live.** OSV's PyPI matching normalizes names and PEP 440 versions, so versions are sent exactly as the lock writes them. A real uv inventory of 17 packages found advisories for requests 2.19.0, jinja2 2.11.2, pyyaml 5.3, urllib3 1.23 and idna 2.7.
- **First review (REQUEST CHANGES at 122cd1a): 2 blocking, 8 non-blocking; all fixed in c6a61b8.**
  - Blocking: pip's line splitting and decoding, and uv's `[[distribution]]` alias.
  - Non-blocking: lost direct marks and the lock's direct marks overriding requirements.txt, bounded messages, stack overflows, other requirements file names, and manifests no lock covers.
  - The re-review confirmed each fix by reverting it: 21 of the 62 tests fail against the old sources.
- **Re-review (REQUEST CHANGES at c6a61b8): 1 blocking, 3 non-blocking; all fixed in the next commit.**
  - **Blocking: a quadratic regex.** `local()` searched for `[...]$` unanchored. A 4 MiB requirements.txt of `./` followed by `[` would have taken about 2 hours; at N = 160,000 the old regex alone took 10.9 s. The test is now anchored, and the same 4 MiB file reads in 36 ms. Every regex in both source files was audited; the rest are anchored or linear. Nine 4 MiB requirements.txt shapes and three TOML shapes are timing tests, each under 1 s.
  - **Tests for pip's line rules:** a comment line ends a continuation, and comments and stripping use Python's whitespace.
  - **Message escapes** now also cover U+061C, U+2060–U+206F, the soft hyphen, U+180E, U+FFF9–U+FFFB, tag characters U+E0000–U+E007F and lone surrogates. A test checks each range.
  - **Option lines** are read as pip's optparse reads them, using pip 26.2.1's option table: arity, unique long-option prefixes, short options with an attached value. A line pip refuses, or one that needs shell quoting, is a limitation.
  - Seven mutants of these fixes are all caught.
  - The escape test found one more bug, now fixed: pyproject.toml requirement names allowed any JS whitespace before them. PEP 508 allows only a space or a tab.
