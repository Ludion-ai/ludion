# ludion-ai

This is another name for [`ludion`](https://www.npmjs.com/package/ludion). The real package is `ludion`. Use `npx ludion`.

`npx ludion-ai <command>` runs `ludion <command>` with the same arguments: it does nothing else.

```sh
npx ludion sync
```

Ludion tells your coding assistant what changed in the versions your project installed: <https://ludion.ai>.

Versions 0.0.x of `ludion-ai` were an earlier, unrelated project and are replaced by this one.
